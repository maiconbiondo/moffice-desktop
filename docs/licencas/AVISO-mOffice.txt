O QUE É O mOffice
------------------

O mOffice é uma suíte de escritório para Windows com três aplicativos:
mTexto (documentos), mPlanilha (planilhas) e mSlides (apresentações).
Ele abre, edita e salva documentos no próprio computador, sem enviar os
documentos para a internet.

O mOffice é baseado no ONLYOFFICE Desktop Editors versão 9.4.0.129,
desenvolvido originalmente por Ascensio System SIA. Ele é uma VERSÃO
MODIFICADA: não é o ONLYOFFICE Desktop Editors, não é publicado nem
endossado pela Ascensio System SIA e não deve ser confundido com o
produto original. O mOffice redistribui o motor de edição do ONLYOFFICE
(o conversor x2t e os editores sdkjs e web-apps) dentro de uma casca
própria, escrita do zero. As modificações feitas no motor estão listadas,
arquivo a arquivo e com data, em licencas\MODIFICACOES-ONLYOFFICE.md.
